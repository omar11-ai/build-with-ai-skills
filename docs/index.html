Agent workflow

Stop prompting. Start specifying.

Six skills that take any project from a vague idea to a shipped, verified product — discovery, scope cutting, PRD, technical spec, verified build, and public launch.

Get the skills on GitHub See DocuMentor

The pipeline

SkillProducesWhat it solves
1-startlearner-profile.mdLearns your background so later steps are calibrated to you
2-scopescope.mdFlipped-interaction interview; cuts the idea to a proof of concept
3-prdprd.mdCore journey, every behavior, states, edge cases, firm scope boundary
4-specspec.mdStack, components, data model, file structure
5-buildworking codeOrdered steps, each verified and committed before the next
6-shippublic repo + submissionPoC verification, demo video script, written submission

Install

git clone https://github.com/omar11-ai/build-with-ai-skills.git ~/.config/opencode/skills

Per project: mkdir -p .opencode/skills && cp -r skills/* .opencode/skills/

Why it works

  • Context is never lost. Each skill reads the previous skill's artifact from disk.
  • Scope gets cut, not expanded. 2-scope and 3-prd refuse to proceed until the boundary is firm.
  • Verification is structural. 5-build commits only after a step passes; 6-ship verifies before anything goes public.
